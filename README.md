# Práctica 2 - Maquetación HTML5

## Descripción

El objetivo de esta práctica es reproducir mediante HTML5 la estructura
y el contenido de dos páginas relacionadas con un servicio de hosting
para WordPress.

En esta primera etapa se trabajará principalmente con la estructura
HTML, dejando los detalles de diseño y estilos CSS para una práctica
posterior.

## Plan de trabajo

| #   | Actividad                                          | Tiempo estimado |
| --- | -------------------------------------------------- | --------------: |
| 1   | Analizar y dividir las interfaces                  |           4 min |
| 2   | Crear estructura inicial del proyecto              |           2 min |
| 3   | Crear estructura HTML de la página de planes       |           5 min |
| 4   | Crear las tarjetas de los tres planes              |           2 min |
| 5   | Agregar información de los planes                  |           3 min |
| 6   | Crear estructura HTML de la página de herramientas |           3 min |
| 7   | Crear sección de soporte                           |           3 min |
| 8   | Crear sección de herramientas                      |           2 min |
| 9   | Revisar títulos, listas y párrafos                 |           3 min |
| 10  | Probar las páginas                                 |           3 min |
| 11  | Revisar y corregir HTML                            |           3 min |
| 12  | Actualizar documentación                           |           3 min |
| 13  | Registrar cambios en Git/GitHub                    |           3 min |

**Tiempo total estimado: 4 horas 20 minutos**

## Tecnologías utilizadas

- Git
- GitHub

## Páginas realizadas

### Página 1 - Planes de WordPress

La primera página contiene:

- Encabezado principal.
- Información promocional.
- Plan StartUp.
- Plan GrowBig.
- Plan GoGeek.
- Precios.
- Características de cada plan.
- Botones para seleccionar cada plan.

### Página 2 - Herramientas para WordPress

La segunda página contiene:

- Sección de soporte.
- Disponibilidad de soporte.
- Experiencia con WordPress.
- Tiempo de respuesta.
- Instalación gratuita.
- Herramientas para webmasters.
- Certificados SSL.
- Copias de seguridad.
- Servicio de correo.
- Herramienta de staging.
- Dev Toolkit.
- CDN.
